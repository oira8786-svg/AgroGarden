# AgroGarden

Android-приложение для садоводов и фермеров.

Включает архитектурную основу production-версии:
- Kotlin + Jetpack Compose
- Room — локальная БД с сущностями посевов, семян, удобрений, поливов, продаж, урожая, расходов, обработок и задач
- WorkManager-зависимость и NotificationWorker для напоминаний
- Android notification channel
- резервное копирование через стандартный `allowBackup`
- готовая база для экспорта/импорта данных

UI MVP содержит добавление/удаление записей и контроль минимального остатка удобрений. Остальные разделы заложены в модели Room и навигационной структуре.

## Сборка
Откройте проект в Android Studio (Jellyfish/Koala или новее), дождитесь Gradle Sync и запустите `app`.

Для полноценного production-релиза рекомендуется дополнить:
1. экранные формы всех сущностей с валидацией;
2. точное планирование повторяющихся WorkManager-задач по датам/часам;
3. CSV/JSON экспорт и импорт;
4. автоматический backup/restore Room DB;
5. тесты, ProGuard/R8 и подпись release APK/AAB;
6. локализацию и UX-аудит на телефонах разных размеров.

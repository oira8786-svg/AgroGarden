# FAYOZAGRO

Полнофункциональное Android-приложение для управления фермерским хозяйством.

## Возможности
- 🌾 Посевы — добавление, редактирование, удаление, площадь, даты, статус и примечания.
- 🌱 Семена — количество, единицы, партии, срок годности, редактирование.
- 🧪 Удобрения — остаток, единица, минимальный запас и предупреждения.
- 💧 Полив — культура, дата, время, объём и периодичность.
- 🔔 Напоминания — задачи, статус выполнения и повторение.
- 💰 Продажи — количество, цена, покупатель, дата и автоматическая выручка.
- 🧺 Урожай — количество, дата и качество.
- 📉 Расходы — категория, сумма, дата и комментарий.
- 📊 Прибыль — автоматический расчёт выручки минус расходы.
- 🛡️ Обработки — болезни/вредители, препараты, даты и заметки.
- 📅 Календарь — сводка поливов и задач.
- 📦 Склад — семена и удобрения.
- 📝 Блокнот — локальные заметки.
- 💾 Room — локальное хранение данных после закрытия приложения.
- 🔄 WorkManager — основа для повторяющихся фоновых задач.
- 📤/📥 Резервное копирование и импорт/экспорт подготовлены для production-развития.

## Редактирование
Во всех основных разделах доступны **Добавить → Изменить → Удалить**, поиск и расширенные поля.

## Сборка APK
GitHub Actions автоматически выполняет `gradle assembleDebug` при каждом push в `main` и публикует `app-debug.apk` как artifact.

Название приложения: **FAYOZAGRO**.
